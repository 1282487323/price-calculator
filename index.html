计算逻辑拆解（与 Excel 公式一一对应）
  1. 计算价格 = (输入价 − 减价常数) × 折扣率
  2. 差价 = 若 (原定价−计算价格) 首位为 “0”（即小于 1），取前 5 位字符保留小数；否则取整数 INT。
  3. 最终价格 = 差价<1 → 计算价格；差价≤4 → 计算价格+差价；否则 计算价格+4。
  4. 是否报活动 = 差价≥4 → “加4”；差价=3 → “加3”；差价=2 → “加2”；差价<2 → “不报活动”。
  5. 原报活动后价格 = 不报活动 → 最终价格；否则 最终价格 − 右位加幅 − 减几。
  6. 最终报活动 = 原报活动后价格≥8 → 维持原方案；否则按差距与加幅降级为 “加N” 或 “不报活动”。
  7. 最终报活动 = 不报活动 → 不报活动；否则 “减” + (右位 + 减几)。
